## Overview
The AI Desktop Virtual Assistant is a program that can perform tasks and provide information to users through voice commands or keyboard input. It streamlines daily activities, making technology more accessible and user-friendly.

## Features
- **Voice Command Recognition**: Interact with the assistant using natural language.
- **Text Input**: Type commands and receive responses.
- **Task Automation**: Perform various tasks like opening applications and retrieving information.
- **All Records Saved**: Keep a log of interactions for future reference.
